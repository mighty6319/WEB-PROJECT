## 📋 Projects Overview

### 1. College Admission Form

**Location:** `collegeadmissionform/`

#### Description
A comprehensive college admission form application built with HTML, CSS, and JavaScript. This project demonstrates form handling, validation, and user interface enhancements.

#### Features
- 📝 **Student Information Form** - Collects essential student details including:
  - Name (with character limit)
  - Age
  - Email
  - Gender
  - Academic information
  - Other admission-related fields

- 🌈 **Rainbow Mode** - Toggle rainbow color theme for visual appeal
- 🌙 **Dark Mode** - Dark mode toggle for better accessibility and user comfort
- ✅ **Form Validation** - Client-side validation for form inputs
- 💾 **Form Submission** - Handles form submission with error handling
- 📱 **Responsive Design** - Works across different device sizes

#### Files
- `collegeadmissionform.html` - Main HTML structure with form elements
- `style.css` - Styling and responsive design
- `script1.js` - Form handling, validation, and DOM manipulation
- `script2.js` - Additional functionality for themes and utilities
- `sumitted.html` - Submission confirmation page

#### Technologies Used
- **HTML5** - Semantic markup and form structure
- **CSS3** - Styling, animations, and responsive design
- **JavaScript (Vanilla)** - Form validation, DOM manipulation, theme switching

#### How to Use
1. Open `collegeadmissionform.html` in a web browser
2. Fill in the required information in the form fields
3. Toggle **Rainbow** or **Dark Mode** buttons for theme options
4. Click **Submit** to submit the form
5. Upon successful submission, you'll be redirected to the confirmation page

#### Features Explained
- **Name Input**: Accepts up to 30 characters with real-time character counting
- **Form Validation**: Ensures all required fields are filled correctly
- **Error Handling**: Displays user-friendly error messages for invalid inputs
- **Theme Toggle**: Switch between light, dark, and rainbow color schemes seamlessly
